# po-helper-landing

Подсайт `po-system.aleksishmanov.ru`: методология и витрина виджетов экосистемы po-helper-org (презентация организации и ценности для заказчиков).
Спек и тикеты живут в основном репозитории (`aleksishmanov-landing`, каталог `.scratch/po-system/`), ADR 0007 — про хостинг. Словарь: **подсайт**, **виджет** (см. `CONTEXT.md` там же).

## Стек и ограничения

- Astro 5 + TypeScript, статика. Сайт живёт в корне своего поддомена (`site` в `astro.config.mjs`, без `base`); внутренние ссылки — через `href()` из `src/lib/site.ts`.
- Без React, Tailwind, UI-библиотек и сторонних доменов. Стили — чистый CSS с переменными в `src/styles/global.css`; шрифт Inter самохостингом через `@fontsource-variable/inter`; анимации — CSS и `IntersectionObserver`, при `prefers-reduced-motion` отключаются.
- Ни форм, ни бэкенда. «Обсудить внедрение» ведёт в Telegram (`t.me/kibarik`).
- Нет зависимостей от основного репозитория. Общие с основным сайтом только данные (контакты, профили), они скопированы сюда.
- Репозиторий публичный: никаких секретов и корпоративных идентификаторов; закрытые виджеты описываются словами, ссылок на закрытые репозитории нет.
- Подсайт сам отдаёт `robots.txt`, `sitemap.xml` и `llms.txt`; основной сайт на них только ссылается.

## Контент

- Узлы методологии (`src/content/method/`) и виджеты (`src/content/widgets/`) — markdown-файлы со схемами zod в `src/lib/schemas.ts`: сборка падает, если поле пропущено.
- Методология перенесена 2026-10-27 из основного репозитория: только узлы со статусом `ready` (проблема, 5 стадий, 2 основания, ответвление). Узлы `draft` и `planned` не переносились. Адреса: `/method/<slug>/`, плоские.
- Ссылки на материалы основного сайта — абсолютные (`https://aleksishmanov.ru/<раздел>/<slug>/`); в front matter узла — ключи `<раздел>/<slug>`. Список существующих материалов — `src/data/materials.json`, его обновляет `node scripts/sync-materials.mjs <путь к aleksishmanov-landing>`. Это единственное место, где подсайт читает основной репозиторий.
- Таблица старых адресов `/method/…` → `https://po-system.aleksishmanov.ru/method/…` — `src/data/method-redirects.json` (нужна основному сайту для 301).
- Виджет: статус `работает` / `в разработке` / `заморожен` / `закрытый`. Закрытый виджет не может иметь `repo`, но обязан иметь `note`; в тексте нет ссылок. Публичные ссылки — только на репозитории `po-helper-org`. Статусы и тексты виджетов написаны по описаниям репозиториев на GitHub и требуют проверки владельцем.

## Проверка

`npm run verify` — типы (`astro check`), Vitest (`tests/unit/`) и Playwright (`tests/e2e/`) против собранного Docker-образа с тем же `nginx.conf`, что на проде. Нужен запущенный Docker; с `BASE_URL=https://…` e2e идут по живому адресу без сборки.
Изменение считается готовым, когда `npm run verify` зелёный.

## Деплой

`Dockerfile` собирает статику и кладёт её в nginx в `/usr/share/nginx/html`. Деплой — приложение Dokploy на домене `po-system.aleksishmanov.ru`, автодеплой пушем в `main`.
