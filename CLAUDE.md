# po-helper-landing

Подсайт `aleksishmanov.ru/po-system/`: методология и витрина виджетов экосистемы po-helper-org (презентация организации и ценности для заказчиков).
Спек и тикеты живут в основном репозитории (`aleksishmanov-landing`, каталог `.scratch/po-system/`), ADR 0007 — про хостинг. Словарь: **подсайт**, **виджет** (см. `CONTEXT.md` там же).

## Стек и ограничения

- Astro 5 + TypeScript, статика. Префикс адреса `/po-system` задан в `astro.config.mjs` (`base`); все ссылки и ресурсы — только через `import.meta.env.BASE_URL`, без жёстких корневых путей.
- Без React, Tailwind, UI-библиотек и сторонних доменов. Стили — чистый CSS с переменными в `src/styles/global.css`; шрифт Inter самохостингом через `@fontsource-variable/inter`; анимации — CSS и `IntersectionObserver`, при `prefers-reduced-motion` отключаются.
- Ни форм, ни бэкенда. «Обсудить внедрение» ведёт в Telegram (`t.me/kibarik`).
- Нет зависимостей от основного репозитория. Общие с основным сайтом только данные (контакты, профили), они скопированы сюда.
- Репозиторий публичный: никаких секретов и корпоративных идентификаторов; закрытые виджеты описываются словами, ссылок на закрытые репозитории нет.
- Подсайт не создаёт корневые `robots.txt` и `sitemap-index.xml`. Он выпускает `sitemap-po-system.xml` и `llms-po-system.txt`, основной сайт подхватывает их.

## Контент (появится в тикетах 03–04)

- Узлы методологии и виджеты — markdown-файлы в `src/content/` со схемой zod: сборка должна падать, если поле пропущено.
- Закрытый виджет не может иметь ссылку на репозиторий; ссылки на материалы — абсолютные адреса aleksishmanov.ru.

## Проверка

`npm run verify` — типы (`astro check`), Vitest (`tests/unit/`) и Playwright (`tests/e2e/`) против собранного Docker-образа с тем же `nginx.conf`, что на проде. Нужен запущенный Docker; с `BASE_URL=https://…` e2e идут по живому адресу без сборки.
Изменение считается готовым, когда `npm run verify` зелёный.

## Деплой

`Dockerfile` собирает статику и кладёт её в nginx под `/usr/share/nginx/html/po-system`. Деплой — приложение Dokploy на пути `/po-system`, автодеплой пушем в `main`.
